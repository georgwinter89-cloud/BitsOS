`cp437-8x16.bin`: the CP437 8x16 VGA font from SeaVGABIOS (`vgasrc/vgafonts.c`, from Joseph Gil's
`fntcol16.zip`, stated there as public domain), copied from V1 (`BitsOS-Plattform/fonts/font16.bin`). 256 glyphs,
16 bytes each, top row first, bit 7 = leftmost pixel. IN-3 replaces it with sizes chosen from the mode.
