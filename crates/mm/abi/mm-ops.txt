# MM-5a ABI script: wave-A memory calls for anonymous memory. Runs on CachyOS (host/tests/mm/abi/mmops.c,
# output in linux-expected.txt), in the kernel (ktest mm.as.abi_diff) and on the pure model (cargo test -p mm).
# B = a free window, H = the program break before the first line, L = the last mmap result. One space
