# Netzteil: wie viel Watt?

CPU 88 W (Boost bis 142 W), Grafikkarte 263 W, Rest 60 W: Spitze etwa 470 W.
Ein 750-W-Gold-Netzteil arbeitet bei 40 bis 60 Prozent Last am effizientesten.
Die Grafikkarte braucht zwei 8-Pin-PCIe-Stecker, getrennte Kabel, keine Y-Verteiler.
Modular, damit der Kabelsalat klein bleibt.
