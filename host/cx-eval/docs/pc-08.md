# Zusammenbau, Reihenfolge

1. Mainboard auf Karton legen, CPU einsetzen (Pfeil beachten), RAM, M.2 mit Kühlkörper
2. Kühler montieren, Wärmeleitpaste: erbsengroß
3. Blende einsetzen, Board verschrauben, Abstandshalter prüfen
4. Netzteil, Kabel ATX 24-Pin und CPU 8-Pin, Grafikkarte zuletzt
5. Front-Anschlüsse nach Handbuch: Power, Reset, USB, Audio
6. Erster Start: nur mit einem RAM-Riegel, dann beide
Erdung: vorher einmal an die Heizung fassen.
