# Rindergulasch (Omas Art)

Für 4 Personen: 800 g Rindergulasch, 4 Zwiebeln, 2 EL Paprikapulver edelsüß, 2 EL Tomatenmark,
300 ml Rotwein, 400 ml Brühe, Lorbeer, Kümmel, Majoran.
Fleisch scharf anbraten, Zwiebeln dazu, Tomatenmark rösten, ablöschen. 2 Stunden bei kleiner
Hitze schmoren, bis das Fleisch zerfällt. Dazu Spätzle oder Kartoffeln.
