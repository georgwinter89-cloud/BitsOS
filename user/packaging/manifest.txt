# UL-5: the package manifest, read by `cargo xtask image`, `initrd` and `stick` (host/xtask/src/package.rs).
# The user workspace, user/c and the ABI-diff programs still go into the initramfs /bin by themselves; this file
# adds programs from elsewhere and says where each goes. One entry per line: <place> <name> <source>
#   place   initrd  /bin/<name> in the initramfs (RAM after boot; travels with every Reload and install_kernel)
#           data    a data file or directory tree in the initramfs; <name> is then its absolute V2 path and the
#                   source host:/abs/path (a directory is copied whole, sorted; pacman's licence texts come along)
#           stick   \BITSOS2\bin\<name> on the stick = /boot/BITSOS2/bin/<name> on V2 (FS-7 mounts the stick at
#                   /boot; read from the stick when run, for programs too big to keep in RAM; the shell's PATH
#                   ends with it)
#           tree    YT-2: a whole directory \BITSOS2\<name>\ on the stick (/boot/BITSOS2/<name>); the source is
#                   host:/abs/dir, copied with its relative paths (FAT-safe names only, empty directories left
#                   out); the libraries its programs need beyond the initramfs set go to its own lib\ (RPATH
#                   $ORIGIN/lib), the rest of the set stays in the initramfs. A tree's name may equal a program's.
#                   BR-2: so do the needs of the shared libraries the source has in its lib\ (dlopened ones).
#                   A ktest image carries a tree only if its filter can run the tree's ktests ul.pkg.<name>*
#                   (V2_STICK_TREES=1 or =<name>,<name> puts trees into any image; image.rs tree_wanted).
#   source  host:/abs/path    a CachyOS file copied unchanged; a dynamic one pulls its libraries into the set
#           file:rel/path     YT-2: a file of this repository copied unchanged (a launcher script; for data: a configuration file)
#           g++:rel/path.cc   built with the host's g++ against CachyOS's glibc and libstdc++ (PIE, dynamic)
#           gcc:rel/path.c    built with the host's gcc against CachyOS's glibc (PIE, dynamic)
#           cargo:rel/dir     the binary <name> of the cargo package in rel/dir, built for the host (CachyOS glibc,
#                             dynamic) with --release --locked --offline --no-default-features, stripped, x86-64-v3
#           localedef:<locale>/<charmap>  UL-6, data only: a glibc locale directory made by the host's localedef
#                             (--no-archive) from /usr/share/i18n; a file equal to an earlier data file becomes a link
# A source the host lacks fails the build; V2_PKG_OPTIONAL=1 leaves it out with a note (the ktests then skip).

# The library-set check (ktest ul.pkg.cxx): exceptions through libgcc_s, iostreams, threads, libm.
initrd pkg-cxx  g++:user/packaging/tests/pkg-cxx.cc
# UL-6: the ABI-diff locale program (ul.pkg.locale compares its output with pkg-locale.out, made on CachyOS).
initrd pkg-locale gcc:user/abi-tests/dyn/locale.c
# A CachyOS C++ program run from the stick (ktest ul.pkg.stick): libstdc++, libgcc_s, libm, libc.
stick  ninja    host:/usr/bin/ninja

# SN-4: ALSA on V2 (card 0 = the mixer). CachyOS's aplay and speaker-test (alsa-utils; libasound comes by ldd)
